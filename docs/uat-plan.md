# User acceptance test plan

UAT must run on staging with approved representative data and named business users. Record tester, date, role, scenario, expected result, actual result, evidence link, defect, severity, retest, and sign-off.

Required scenarios cover authentication and password recovery; employee provisioning and branch restrictions; product/price/image management; opening stock, count, adjustment, and negative-stock prevention; purchase/order/receipt/payment; cash and credit sale/payment/reversal/cancellation; transfer request/approval/dispatch/receipt; dashboards and report reconciliation; public catalogue/search/filter/quotation; responsive mobile operation; denied unauthorized/cross-branch actions; and backup/restore evidence.

Exit criteria: no unresolved critical/high defect, all financial and stock reconciliations match approved expectations, owner accepts public content, role owners accept permissions, restore evidence is approved, and rollback/cutover owners are assigned. Automated tests do not substitute for business acceptance.
